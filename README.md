# tensor

Общий репозиторий для работы с проектом в облачном Codex и локальном VS Code.
Код проекта пока не добавлен.

## Открыть в VS Code

В VS Code выберите **Git: Clone** в палитре команд и укажите:

```text
https://github.com/leda-we/tensor.git
```

Выберите папку на компьютере и откройте клонированный репозиторий.
Если GitHub запросит авторизацию, войдите через предложенное окно браузера.
Установите официальное расширение Codex от OpenAI и войдите в свой аккаунт.

## Получить изменения

Перед новой работой сохраните свои изменения коммитом либо временно уберите
их через Git stash. Затем в терминале папки проекта выполните:

```sh
git switch main
git pull --ff-only origin main
```

Если Git сообщает о разошедшейся истории, сначала разберите расхождения;
не используйте принудительную отправку или сброс своих изменений.

## Передать изменения

В панели Source Control проверьте изменения и добавьте в индекс только нужные
файлы. Не добавляйте пароли, токены и файлы с секретами. Создайте коммит
с описанием и нажмите **Push**. Эквивалент после добавления файлов в индекс:

```sh
git commit -m "Describe the changes"
git push origin main
```

В облачной задаче попросите Codex получить последние изменения из GitHub
перед работой и отправить законченные изменения в репозиторий после проверки.
Если задача использует отдельную ветку, сначала объедините её с main через
pull request, затем получите main в VS Code.

Git синхронизирует отправленные коммиты. Несохранённые правки, локальные
файлы без коммита и история чата автоматически между средами не передаются.
